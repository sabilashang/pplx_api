                    └── Perplexity API (external)

================================================================================
ADDING NEW FILES
================================================================================

To add a new model/tab:
  1. Create: app/api/[model-name]/route.ts
  2. Update: app/components/Tabs.tsx (add to tabs array)
  3. Restart: npm run dev

To add a new component:
  1. Create: app/components/NewComponent.tsx
  2. Import: in app/page.tsx
  3. Use: <NewComponent />

To add a new utility:
  1. Create: lib/utility-name.ts
  2. Export: functions/types
  3. Import: from '@/lib/utility-name'

================================================================================
TYPICAL WORKFLOW
================================================================================

Day 1 - Setup:
  1. cd pplx_api
  2. npm install
  3. Create .env.local with API key
  4. npm run dev
  5. Open http://localhost:3000

Daily Development:
  1. npm run dev (start server)
  2. Edit files in app/ or lib/
  3. Browser auto-refreshes
  4. Check console for errors
  5. Ctrl+C to stop

Before Deployment:
  1. npm run build (test build)
  2. npm start (test production)
  3. Fix any errors
  4. Deploy to platform
  5. Set PERPLEXITY_API_KEY in platform
