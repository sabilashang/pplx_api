================================================================================
                        🐛 TROUBLESHOOTING
================================================================================

PROBLEM: "Cannot find module"
SOLUTION: npm install

PROBLEM: "API key not configured"
SOLUTION: 
  1. Create .env.local file in project root
  2. Add: PERPLEXITY_API_KEY=pplx-your-key-here
  3. Restart server (Ctrl+C then npm run dev)

PROBLEM: "Port 3000 already in use"
SOLUTION: npm run dev -- -p 3001
          Then open http://localhost:3001

PROBLEM: "Authentication failed"
SOLUTION: 
  1. Get new API key from https://www.perplexity.ai/settings/api
  2. Update .env.local
  3. Restart server

PROBLEM: Very slow response (>30s)
SOLUTION: 
  - Check internet connection
  - Try shorter text
  - Try faster models (Reasoning, Search API)

PROBLEM: Timer shows but no response
SOLUTION: 
  - Search models take 15-20 seconds (normal)
  - Wait patiently
  - If >30s, check server logs for errors

================================================================================

1. START WITH FAST MODELS
   ✅ Try Search API first (2s response)
   ✅ Then Sonar Reasoning (3-5s)
   ✅ This confirms everything works quickly

2. COMPARE RESPONSE TIMES
   ✅ Test same text on different models
   ✅ Note the duration differences
   ✅ Understand which models are fastest

3. WATCH TOKEN USAGE
   ✅ More tokens = higher cost
   ✅ UI shows exact token counts
   ✅ Compare efficiency across models

4. USE KEYBOARD SHORTCUTS
   ✅ Ctrl+Enter (Win) / Cmd+Enter (Mac) to submit
   ✅ Faster than clicking button

5. MONITOR SERVER LOGS
   ✅ Watch terminal for real-time processing times
   ✅ See exactly when requests start/finish
   ✅ Useful for debugging
